Notifications Instantanées sur Smartphone & PC (Telegram)

Recevez un message dès qu'un enseignant s'inscrit ou démarre son essai
🚀 Comment configurer en 2 minutes (100% gratuit) :
  1. Ouvrez l'application Telegram (sur votre téléphone ou ordinateur) et recherchez @BotFather.
  2. Envoyez la commande /newbot, donnez un nom à votre bot (ex: PedagoAlertBot) et copiez le Token API fourni.
  3. Envoyez un premier message (ex: "Salut") à votre bot créé, puis recherchez @userinfobot sur Telegram pour obtenir votre Chat ID personnel.
  4. Renseignez ces 2 variables dans les Paramètres Secrets de votre application :
    • TELEGRAM_BOT_TOKEN = votre token de bot
    • TELEGRAM_CHAT_ID = votre chat ID personnel
