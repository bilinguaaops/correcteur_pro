Recevez instantanément chaque nouveau professeur dans Google Sheets, Zapier, Make, Telegram ou Formspree dès qu'il s'inscrit.

📋 Comment créer un Google Sheet en 1 minute (Code Google Apps Script)
1. Ouvrez un nouveau Google Sheet.
2. Allez dans Extensions > Apps Script, collez le code ci-dessous et cliquez sur Déployer > Nouveau déploiement > Application Web (Accès : Tout le monde) : 
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var d = JSON.parse(e.postData.contents);
  var lead = d.data || d;
  sheet.appendRow([new Date(), lead.name||'', lead.email||'', lead.whatsapp||'', lead.school||'', lead.plan||'free']);
  return ContentService.createTextOutput(JSON.stringify({result: 'ok'})).setMimeType(ContentService.MimeType.JSON);
}
3. Copiez l'URL de l'application Web et collez-la dans le champ ci-dessus !
